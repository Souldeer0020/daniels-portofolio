# daniels-portofolio
A sample portfolio website created using HTML, CSS, and JavaScript. This project was built for practice and demonstrates core front-end concepts such as layout design, responsiveness, and basic interactivity.
Portfolio Website Template

This project is a portfolio website template built using HTML, CSS, JavaScript, Bootstrap, and Font Awesome. It demonstrates core front-end development concepts such as responsive layout design, reusable components, and basic interactivity.

The website is fully responsive thanks to Bootstrap’s grid system and includes icons provided by Font Awesome. It can be easily customized and reused for different individuals or projects.

Technologies Used

  * HTML5

  * CSS3

  * JavaScript

  * Bootstrap

  * Font Awesome

Features

  * Responsive design for all screen sizes

  * Clean and modern UI

  * Reusable layout and components

  * Font Awesome icons

  * Easy to customize content
